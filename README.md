# Student Management System

A Java-based Student Management System developed using Eclipse IDE.

## Features
- Add Student
- View Students
- Search Student
- Delete Student
- Save and Load Student Data

## Technologies Used
- Java
- Eclipse IDE
- Object-Oriented Programming
- File Handling

## Project Files
- Main.java
- Student.java
- StudentService.java

## How to Run
1. Open the project in Eclipse IDE.
2. Open Main.java.
3. Right-click and select Run As → Java Application.
